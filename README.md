# WEB103 Prework - creatorverse

Submitted by: Kritazya Upreti

About this web app: Creatorverse is a sleek, modern styled web application desgined to curate, showcase, and manage your favorite digital content creators in a single centralized hub. It connects a highly responsive React frontend with a scalable Supabase cloud database backend.

**Core Features**

- Dynamic Dashboard: Displays all content creators in a clean, responsive grid layout of interactive profile cards featuring their images, bios, and social connections.
- Complete CRUD Management: Enables full data control to effortlessly add new creator profiles, view detailed breakdowns, modify existing data, or delete records in real-time.
- Seamless Clould Persistence: Leverages asynchronous Supabase integration to fetch, insert, and update database rows directly from the client interface without laggy page refreshes.

Time spent: 20 hours
